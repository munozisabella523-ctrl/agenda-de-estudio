# Agenda de estudio

Práctica guiada de programación de Isabella Muñoz Arias.

## Objetivo y funcionamiento

Permite agregar tareas, marcarlas como completadas y eliminarlas. Intenta conservar los datos con localStorage. El guardado depende del navegador y no sincroniza entre dispositivos.

## Tecnologías

HTML, CSS y JavaScript. No requiere compilación ni dependencias.

## Abrir

Abre `index.html` con un navegador. Para la agenda se recomienda usar un servidor local o la demostración publicada para disponer de un origen estable para localStorage.

## Demostración

https://munozisabella523-ctrl.github.io/portafolio-programacion-isabella/agenda.html

## Archivos

- `index.html`: interfaz y formulario.
- `styles.css`: diseño adaptable.
- `app.js`: lógica de la práctica.

## Aprendizaje

Este ejercicio se preparó con asistencia de IA como material de estudio. Debe ser revisado, adaptado y comprendido antes de presentarlo como evidencia de aprendizaje propio. No se atribuye como experiencia previa de la estudiante.
